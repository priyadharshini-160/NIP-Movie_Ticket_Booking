# NIP-Movie_Ticket_Booking
# 🎬 Movie Ticket Booking System

## About the Project

The **Movie Ticket Booking System** is a Pega-based application that allows users to browse movies and book movie tickets through an easy and automated workflow.

## Features

* View available movies
* Select a movie
* Choose date and show
* Select seats
* Enter customer details
* Confirm ticket booking
* Manage booking details

## Technology Used

* Pega Platform
* Pega App Studio
* Case Management
* Workflow Automation
* Constellation UI

## Workflow

**Select Movie → Select Show → Select Seats → Enter Details → Confirm Booking**
